Remove `mixins/column_suggestion.py`, whose single module carried both halves of the suggestion question; it is replaced by `mixins/column_type.py` (the column-class answer) and `protocols/data_type.py` (the storage answer), which state each half's shape instead of leaving it to a naming convention. Remove the six Oracle `DataType` classes that rendered exactly what their core parent renders — `OracleIntegerType`, `OracleSmallIntType`, `OracleBigIntType`, `OracleVarChar2Type`, `OracleCharType` and `OracleBlobType` — because `DataType.__eq__` is `type(self) is type(other)`, so a class whose only difference is its name made a declaration and the introspection row it produced compare unequal while rendering byte-identical SQL, and the schema differ reported the column as changed; use the core `IntegerType` / `SmallIntType` / `BigIntType` / `VarCharType` / `CharType` / `BlobType` instead, which render the same words and now compare equal to what `parse_type` returns. Remove the `columns_type` bulk DDL-source accessor, superseded by `columns_data_type()`.
