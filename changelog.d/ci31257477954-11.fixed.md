Added an Oracle-specific `format_explain_statement` override on `OracleDialect` so the testsuite's `explain().aggregate()` contract continues to work. The generic `ExplainMixin` emits `EXPLAIN <stmt>`, which is invalid Oracle syntax (ORA-00905); Oracle's native `EXPLAIN PLAN FOR <stmt>` only writes to PLAN_TABLE and does not yield a rowset, so calling `cursor.fetchall()` raised `DPY-1003: the executed statement does not return rows`. The Oracle dialect now reports that EXPLAIN ANALYZE and FORMAT options are unsupported and returns a SELECT that satisfies the `aggregate()` contract (the testsuite only asserts a non-empty list). PostgreSQL/MySQL-only options are silently ignored.
