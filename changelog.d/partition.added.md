Added Oracle partition DDL support: RANGE/LIST/HASH table partitioning (Phase 4) with INTERVAL, REFERENCE, and COMPOSITE (subpartition) strategies (Phase 5). Implemented all 7 partition maintenance DDL statements (ADD/DROP/SPLIT/MERGE/EXCHANGE/MOVE/TRUNCATE PARTITION) via `OraclePartitionMixin`, `OraclePartitionLifecycleMixin`, and backend-specific OraclePartitionDefinition Expression classes. Version-gated to 11g+ with `UnsupportedFeatureError` on pre-11g. Examples and real Oracle tests included.
