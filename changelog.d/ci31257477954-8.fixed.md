Fixed Oracle test schema (`comments.sql`) using `postRef` in foreign-key and index declarations while the corresponding model attribute is mapped to `post_ref`. Because `OracleDialect.format_identifier` uppercases all unquoted identifiers, Oracle rejected the constraint and index with ORA-00904 `"POSTREF": invalid identifier`, which cascaded into `test_field_column_mapping` errors. The schema now consistently uses `post_ref`.
