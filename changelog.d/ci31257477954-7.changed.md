Boosted the Oracle connection capacity used by the CI workflow. After waiting for the container to register the PDB service with the listener, the workflow now raises `processes=600`, `sessions=900` and `dispatchers='(PROTOCOL=TCP)(DISPATCHERS=4)'`, and bounces the container so the spfile-only parameters take effect before the pytest suite starts. This prevents ORA-12516 / DPY-6005 dispatcher exhaustion that surfaced when the testsuite's worker / savepoint / owner-task tests fan out several concurrent backend pools per scenario.
