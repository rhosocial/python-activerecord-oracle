Correct the Oracle date-difference formatter, which wrote the difference the way PostgreSQL writes it — `end - start` is an ORA-00932 here, because `-` is defined for numbers and intervals and not for two DATE columns — and now takes the difference through an interval (`ROUND((CAST(end AS DATE) - CAST(start AS DATE)) * 86400)`, divided down for the coarser units, with `MONTHS_BETWEEN` for the month and year units), returning an integer number of days by default rather than a fraction. Correct the `supports_xmlparse` floor, which answered `version >= (9, 0, 0)` although Oracle's SQL Reference first lists `XMLPARSE` in 10.2; it now answers `(10, 2, 0)`, with the live measurement recorded (the function, including Oracle's `WELLFORMED` extension, executes on 18c / 21c / 23c, while the standard's `PRESERVE WHITESPACE` clause raises ORA-03001 on all three).
