Fixed Oracle `tests/providers/query.py::QueryAsyncProvider.setup_mapped_models` attempting to import `AsyncMappedUser`/`AsyncMappedPost`/`AsyncMappedComment` from `rhosocial.activerecord.testsuite.feature.query.fixtures.async_models`. That module does not define those classes (the ones in `query.fixtures.models` do), so any test pulling in the `async_mapped_models_fixtures` fixture raised `ImportError` during setup. The provider now reuses the `AsyncMappedUserBase`/`AsyncMappedPostBase`/`AsyncMappedCommentBase` aliases already imported at module top-level.
