Fixed `AsyncOracleBackend.executescript` splitting SQL scripts with a naive `split(';')`, which mangled anonymous PL/SQL blocks (e.g. `BEGIN EXECUTE IMMEDIATE ...; EXCEPTION WHEN OTHERS THEN NULL; END;`). The async implementation now delegates to the same state-machine splitter used by the sync backend, so DDL idempotency wrappers such as `_DROP_TABLE_BLOCK` execute as a single statement and stop leaking `ORA-00955: name is already used by an existing object` errors between consecutive async fixture setups.
