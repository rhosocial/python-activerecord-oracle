# rhosocial-activerecord-oracle — Documentation (English)

This is the Oracle backend for [rhosocial-activerecord](https://github.com/rhosocial/python-activerecord). Add it alongside the core library to use Oracle Database through the same ActiveRecord models, queries, and lifecycle API. See the [project README](../../README.md) for installation and a quick start.

## Contents

- [Database Introspection](../introspection.md) — reading Oracle schema metadata.
- [Date/Time Expressions](../datetime-expressions.md) — Oracle date/time handling.
- [Partitioning: DDL, Suggestions and Introspection](../partition.md) — partitioned tables, lifecycle suggestions and introspection.
- [Migrations](migration/README.md) — Oracle-specific migration concerns (the migration system itself is documented in the core chapter).

## Overview

The documentation covers how to use the Oracle backend with the main rhosocial-activerecord package, including configuration, advanced features, and best practices. For the main ActiveRecord framework documentation, visit the [core documentation](https://github.com/rhosocial/python-activerecord/tree/main/docs).
