# expression tests

Oracle expression system: serialization round trips over all Oracle expression classes and the Phase 3 dialect/expressions enhancements (hierarchical queries, PIVOT/UNPIVOT, hints, locking, constraint and transaction capabilities).

## Key files

- `test_expression_roundtrip_all.py` — serialization round trips
- `test_phase3_dialect.py` — phase 3 dialect capability gates
- `test_phase3_expressions.py` — hierarchical / pivot / hint / locking expressions
